# 🏓 Ping-Pong-Game

A simple and interactive Ping Pong game built using **HTML**, **CSS**, and **JavaScript**.

---

## 🏓 PONG AI – Neon Arcade Edition

**PONG AI** is a modern Ping Pong game built using **HTML5 Canvas**, **CSS**, and **JavaScript**, featuring a futuristic neon-themed UI and smooth gameplay directly in the browser.

---

## ✨ Visual Highlights

- Neon glowing title and buttons
- Dark futuristic gradient background
- Smooth canvas design with rounded corners
- Arcade-style visual effects
- Responsive center-aligned layout

---

## 🚀 Features

- HTML5 **Canvas-based** Ping Pong game
- Smooth ball and paddle movement
- Collision detection
- Score tracking
- **RESET** button to restart the game instantly
- Clean and attractive neon UI

---

## 🛠️ Technologies Used

- **HTML5** – game structure & canvas
- **CSS3** – neon gradients, glow effects, modern UI
- **JavaScript** – game logic and animation

## ▶️ How to Run the Game

1. Clone the repository:

   ```bash
   git clone https://github.com/your-username/ping-pong-game.git
   ```

2. Open the project folder

3. Open **index.html** in any modern web browser

- Play directly using keyboard controls defined in the game
